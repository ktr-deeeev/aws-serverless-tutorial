# aws-serverless-tutorial

CloudFront + Lambda のサーバーレス構成を学習目的で構築するリポジトリ。

## 構成

- `frontend/` — React + TypeScript (Vite)
- `backend/` — Lambda ハンドラ（予定）
- `infra/` — Terraform（予定）
- `docs/` — 構成図、ドキュメント

## セットアップ

```bash
pnpm install
pnpm dev
```

## Node / pnpm

Node は Volta、pnpm は `packageManager` フィールドで管理。
